# 💼 Smart Login & Loan System (Python)

## 📌 Description
This project is a simple authentication and loan management system built using Python.  
Users can register, log in, and apply for loans.

---

## 🚀 Features
- 🔐 Secure Login (Password Hashing)
- 👤 User Registration
- 💰 Loan Application System
- 📋 View Loan History
- 💾 JSON Data Storage
- 🖥️ CLI Interface

---

## 🛠️ Tech Stack
- Python
- JSON
- hashlib (for security)

---

## ▶️ How to Run
1. Install Python
2. Run: python main.py

---

## 📂 Project Structure
- main.py → main program
- auth.py → authentication logic
- loan.py → loan system
- utils.py → helper functions
- data.json → database
- README.md → documentation
